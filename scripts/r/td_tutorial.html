Overview

This document walks through the engine’s learning process in detail, using a single short chess game as a concrete example. By the end you should understand:

  • What a weight is and what it represents
  • How the engine evaluates a board position using those weights
  • How a game’s result is used to update the weights via temporal difference learning
  • Why some concepts (like queen value) are learned faster than others

Game

We’ll use Scholar’s Mate — a four-move checkmate — as our example. It’s short enough to trace every step, and it has a decisive result (white wins), which produces a clear learning signal.

The moves are: 1. e4 e5 2. Bc4 Nc6 3. Qh5 Nf6?? 4. Qxf7#

White wins by exploiting the weakness of black’s f7 square. King safety is the critical factor in this game — the engine should learn that from these four positions.

Evaluation

The engine knows nothing about chess strategy on its own. It knows the rules of the game and a handful of features of any board position. The engine then combines the board features into a single score using a weighted sum:

\[\text{score} = w_1 \times feature_1 + w_2 \times feature_2 + \cdots + w_n \times feature_n\] The board features and how they are scored are fixed. What changes are the weights, which update after each move and in response to the game outcome. After lots of games, the weights should come to reflect the true value of each board feature in the game of chess. As the engine’s weights get closer to each feature’s true value in the game of chess, its ability to play the game of chess improves.

A positive score means the position looks good for the side to move; negative means it looks bad. After white moves, the evaluation score is from black’s perspective.

Let’s learn from this game. First, we set the engine.

We will now make a move and do the following: (1) update the feature values, (2) calculate the evaluation score based on the updated feature values and the weights from the previous move, and (3) update the weights using the evaluation score, the error, the learning rate, and the weights from the previous move.

Note what learning has taken place after this game. Black was winning the center but lost. Therefore, the engine thinks control of the center is correlated with losing in general. Black lost the game on king safety, so that gets a correct and relatively high weight.

It’s unclear whether a run of scholar’s mate games would correct the engine’s mistaken impression that center control is bad.
